# 第 6 篇：评估与预测（eval + infer）—— 模型训好后怎么验、怎么用

> 本篇解读 `src/stock_ai/eval/` 与 `src/stock_ai/infer/` 两个子包。训练得到的模型只是「半成品」，真正要回答的是两个问题：**它历史上有多能赚、稳不稳？（回测）** 以及 **面对没见过的新行情，它给什么信号？（预测）**。

---

## 6.1 评估层（eval）—— 回测：在历史数据上「重放」模型

### 6.1.1 回测器（backtester.py 的 `Backtester`）

回测的思路极其直接：**把训练好的模型，放进同一个交易环境里，让它按历史行情再走一遍，记录每一步的账户变化**。

```python
env = TradingEnv(samples, env_cfg, seed=42, action_mode=mode)
obs, _ = env.reset()
while not done:
    action, _ = model.predict(obs, deterministic=True)   # 模型决策
    obs, reward, terminated, truncated, _ = env.step(action)
    # 收集 equity（组合市值）、dates、trades
```

> 注意 `deterministic=True`：回测用「贪心」决策（取概率最大的动作），不再随机探索——因为我们已经在检验「学成的策略」而不是训练中的策略。

### 6.1.2 必设的「懒人基准」：买入持有（buy & hold）

一个策略再花哨，也得和「什么都不做、第一天满仓买入一直持有」比较，才有意义。`_buy_and_hold()` 就是算这个基准曲线。

`compare_with_baseline()` 返回 `{strategy, baseline, excess_return}`——**超额收益**才是策略真正的价值。如果策略跑不赢买入持有，那它大概率只是「牛市Beta」，没有Alpha。

### 6.1.3 模拟器（simulator.py 的 `PortfolioSimulator`）

除了用 Gymnasium 环境逐步回放，本项目还提供了一个**向量化离线模拟器**，复用 `env/rules.py` 的同一套规则（`apply_slippage` / `is_limit_up` / `is_limit_down` / `max_affordable_lots` / `trade_cost`），直接吃 `(actions, prices, dates)` 序列逐日维护账户。它不依赖 gym 步进，适合批量快速回放。

> 小差异：样本契约不含成交量，模拟器按「未停牌」处理；而训练环境有成交量代理可精确判定涨跌停/停牌。两者规则同源，结果一致。

## 6.2 回测指标（metrics.py）—— 怎么才算「好策略」

光看「赚了多少」不够。下面是本项目算的核心指标（`PERIODS_PER_YEAR=252`，A 股一年约 252 个交易日）：

| 指标 | 含义 | 解读 |
|---|---|---|
| `total_return` | 总收益率 `last/first - 1` | 区间累计赚了多少 |
| `annual_return` | 年化收益（按真实天数几何年化） | 抹平时长差异，便于横向比较 |
| `max_drawdown` | 最大回撤（从峰值最大回落幅度） | **越小越好**，衡量「睡得着觉」程度 |
| `sharpe` | 夏普比率（风险调整后收益） | `(年化超额收益) / (收益波动)`，越高越优 |
| `win_rate` | 胜率（盈利平仓笔数 / 总平仓笔数） | 交易质量 |
| `turnover` | 换手率（总成交额 / 平均权益） | 越高摩擦成本越大 |
| `num_trades` | 交易次数 | 结合换手看策略活跃度 |

**背景知识：夏普比率（Sharpe Ratio）**
由诺贝尔经济学奖得主 William Sharpe 提出，衡量「每承担一单位风险，能换来多少超额收益」。粗略说：**同样赚 10%，波动小的那个夏普更高、更值得信任**。公式（年化）：
```
sharpe = (年化收益 − 无风险利率) / 年化收益标准差
```
本项目用 `excess = 日收益 − 日无风险利率`，再 `mean/std × sqrt(252)`。

> 所有指标函数都是**纯函数**（K14），便于单元测试（README 提到「指标对照手算」测试）。

- 最大回撤：https://zh.wikipedia.org/wiki/最大回撤

## 6.3 回测报告与绘图

- `schema.py` 的 `BacktesterResult.to_json(path)` 输出 `reports/backtest_<ts>.json`，结构含 `meta / metrics / equity_curve / baseline_curve / dates / trades`。
- `plot.py` 的 `EquityPlotter` 用 matplotlib（Agg 无头后端，K15）画**策略 vs 买入持有**的权益曲线，自动探测中文字体（失败回退英文，绝不崩），输出 `reports/equity_<ts>.png`。
- `backtest_cli.py`：按 zip 内容自动识别后端（`backend.json → numpy` / `policy.pth → sb3`），再加载对应训练器；读 `models/*.zip` + `test.npz` + `meta.json` → 写报告。

## 6.4 推理层（infer）—— 预测：对未知行情发信号

### 6.4.1 预测器（predictor.py 的 `Predictor`）

预测 = 把模型用在**训练时没见过的新区间**上，输出每日交易信号。

**关键约束（再次强调防泄漏）**：预测**强制要求**传入冻结的 `NormalizerState`（来自 `data/samples/meta.json`），否则抛 `ArtifactError`。绝不允许拿新数据重新 fit 归一化——否则等于把新行情的统计信息偷偷喂进去，破坏了「用历史学的规则去判断未来」的公平性。

流程：
```python
for 每只股票:
    normed = engineer.transform(raw, normalizer)   # 复用冻结状态
    obs = make_obs(normed)                          # 构造滑窗观测
    for 每天:
        action, _ = model.predict(obs)              # 模型决策
        # act==1 买入(position→1); act==2 卖出(position→0)
        # signal: 买=+1, 卖=-1; target_position∈[0,1]
```

### 6.4.2 动作 → 信号映射
- `ACTION_LABELS = {0:"持有", 1:"买", 2:"卖"}`
- `signal`：买入 +1 / 卖出 −1
- `target_position`：目标仓位（0 或 1，或连续模式下的比例）

### 6.4.3 输出
`to_csv` / `to_json` 列：`date, symbol, action, target_position, signal, price`。落盘 `reports/predict_<ts>.csv` 和 `.json`。

`predict_cli.py` 串联：读 `models/*.zip` + `data/samples/meta.json`（冻结归一化）+ `data/raw`（新区间原始价）→ 写预测报告。

## 6.5 这一层的工程亮点

1. **回测用同环境重放**：训练和回测共享 `TradingEnv` + `rules.py`，规则完全一致的「同规则」校验。
2. **买入持有基准**强制对比，避免「牛市里谁都赚钱」的错觉。
3. **纯函数指标 + 手算对照测试**，结果可信。
4. **预测严防泄漏**：强制复用冻结归一化状态，绝不重新 fit。

---

## 6.6 本篇小结

- 回测 = 在同一环境里重放模型，记录权益曲线，并和「买入持有」比超额收益。
- 核心指标：**年化收益、最大回撤、夏普比率、胜率、换手率**——不只看赚多少，更看稳不稳。
- 预测 = 把模型用在未知行情上发买卖信号，**强制复用冻结归一化**以防泄漏。
- 报告以 `backtest_*.json + equity_*.png` 和 `predict_*.csv/json` 落盘，可直接查看。
